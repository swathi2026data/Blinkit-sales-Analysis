# Blinkit Sales Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing Blinkit sales data using Microsoft Power BI. An interactive, 3-page dashboard was developed to present business data in a clear and meaningful visual format.

## Project Objectives
- Analyze Blinkit sales data.
- Present key business metrics through visualizations.
- Understand sales performance and business trends.
- Create an interactive and user-friendly dashboard.

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Dashboard Development
